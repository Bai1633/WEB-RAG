# pgvector 向量索引指南

本系统使用 PostgreSQL 的 pgvector 扩展存储与检索文档向量，每个知识库对应一张独立的向量表。

## 索引类型

pgvector 支持两种近邻索引：

- **HNSW**（分层可导航小世界图）：查询速度快、召回率高，适合大多数场景。本系统默认使用 HNSW，构建参数为 `m = 16`、`ef_construction = 200`，距离度量采用余弦距离（操作符 `<=>`）。
- **IVFFlat**（倒排文件索引）：先聚类再检索，构建更快、占用更低，但需要足量数据才能训练出合理的聚类中心。

## 使用建议

数据量在百万级以下时优先选择 HNSW；批量导入大量向量时可以先建表灌数、最后再创建索引，能显著缩短导入耗时。查询侧可以通过调整 `ef_search` 在召回率与延迟之间权衡。
