# RAG 文档处理流水线

本文档描述知识库问答系统的文档入库流水线：解析、分块、向量化与检索。

## 解析与分块

系统支持 PDF、DOCX、Markdown、HTML、TXT、CSV 六种格式。PDF 使用 pdfplumber 解析，表格会转换为 Markdown 表格保留结构；DOCX 使用 python-docx 按段落与表格顺序提取。

解析后的全文按句子边界分块，默认块大小 512 字符、相邻块重叠 50 字符，兼顾语义完整与上下文连续。

## 检索与重排

在线问答采用三路混合检索：向量检索、pg_trgm 词法检索与 tsvector 全文检索，三路结果使用 RRF（Reciprocal Rank Fusion）融合，融合常数 k = 60。融合后的候选交由 BGE cross-encoder 重排器精排，取前 5 条注入大模型上下文。

当最高重排分数低于拒答阈值 0.35 时，系统不生成回答，而是明确告知用户知识库中未找到相关内容，避免编造。
